## What I work on

My work connects physical models to practical measurements: electromagnetic
simulation, light scattering, fiber photonics, flow cytometry, signal analysis,
and scientific instrumentation. I develop accessible Python interfaces backed
by compiled C++ where performance matters, with testing, documentation,
packaging, and reproducible examples built in.

I am currently a postdoctoral researcher at Amsterdam UMC. I hold a PhD in
Engineering Physics from Polytechnique Montréal and am interested in scientific
software engineering, computational optics, and research collaborations.

## Selected work

| Project | What it does |
| --- | --- |
| **[PyMieSim](https://github.com/MartinPdeS/PyMieSim)** | Fast Lorenz–Mie scattering simulations with source, particle, and detector coupling. Published in *Optics Continuum*. |
| **[FlowCyPy](https://github.com/MartinPdeS/FlowCyPy)** | An end-to-end digital twin for flow cytometry, from particle events and scattering to detector electronics and signals. |
| **[SuPyMode](https://github.com/MartinPdeS/SuPyMode)** | Fiber-component design using eigenmode expansion and coupled-mode theory. Published in *Optics Continuum*. |
| **[LightWave2D](https://github.com/MartinPdeS/LightWave2D)** | Unit-aware 2D FDTD simulations of propagation, scattering, diffraction, and photonic structures. |
| **[PackLab](https://github.com/MartinPdeS/PackLab)** | Hard-sphere structure through Percus–Yevick theory, RSA packing, Metropolis Monte Carlo, and scattering. |
| **[RosettaX](https://github.com/MartinPdeS/RosettaX)** | Interactive fluorescence and scattering calibration for flow-cytometry measurements. |
